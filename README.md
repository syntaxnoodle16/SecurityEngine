# Security Engine

![Logo](art/logo.png)

An Engine/Framework for Five Nights at Freddy's fangames made in [HaxeFlixel](https://haxeflixel.com/).

## NOTICE
This Engine is almost finished, but still has a few quirks. It is stable enough for production use, but is incomplete.

## Features

- A customizable animatronic AI system
- A scrolling office
- Easy to customize cameras
- Easy way to add animatronics with custom paths

And More!

## NOTICE
This Engine/Framework only includes the bare minimum to make a basic fnaf fangame. For more features (like adding a character with custom behavior) you need to add those yourself.
