# How to compile Security Engine

Security Engine uses the HaxeFlixel framework. Here is how to get it running:

1. Download [Haxe 4.3.7](https://haxe.org/download/version/4.3.7/)
2. Download [Git](https://git-scm.com/)
3. Open a terminal and run
    ```bash
    haxelib install flixel
    haxelib run lime setup
    ```
4. Clone the repo by running
    ```bash
    git clone https://github.com/Axolotlguy7707/SecurityEngine.git
    ```
5. Then run
    ```bash
    cd SecurityEngine
    ```
6. Then run
    ```bash
    lime test html5
    ```
